Day 5 · Lenis Smooth Scrolling

One sentence: Lenis adds inertia to scrolling — it intercepts wheel input and drives the native scrollTop through an easing curve, so scrolling becomes a glide. Portfolio usage: enable it site-wide + route anchor links through lenis.scrollTo() — one of the most visible "signature feels" of high-end portfolio sites.

02Tuning inertia: duration is the personality

duration is the total inertia time in seconds: 0.4s is crisp, 1.2s is the standard "butter", 2.2s feels like drifting underwater. Switch live and flick the wheel — notice how far the page glides after you stop. The portfolio sweet spot is 1.0–1.2s.

duration = 1.2s

Switch, then scroll — there is no right answer here, only "what character should this site have".

03Anchor navigation: lenis.scrollTo()

Native <a href="#s1"> teleports — it bypasses Lenis entirely. So intercept anchors and route them through lenis.scrollTo(target, { offset }). Try the nav below: with Lenis on it glides; with Lenis off (toggle back in 01) it degrades to the native jump — graceful, by design.

→ 01 on/off → 02 tuning → 04 GSAP sync

offset clears sticky headers (e.g. { offset: -80 }) — otherwise the target slides under the nav, the most common anchor-scroll visual bug.

04GSAP integration: the three-line sync

Does Day 4's ScrollTrigger fight Lenis? No — three lines bridge them: lenis.on('scroll', ScrollTrigger.update) keeps triggers aligned with Lenis' position, gsap.ticker drives Lenis' raf on one loop, and lagSmoothing(0) disables GSAP's frame-catchup smoothing (otherwise scrolling feels "jelly"). The scrub bar below is the proof — it's running on top of Lenis right now.

scrub progress 0% · Lenis + ScrollTrigger in sync

The minimal runnable code (site-wide, ~30 lines)

<script src="https://unpkg.com/lenis@1.3.4/dist/lenis.min.js"></script>
<script>
const reduced = matchMedia('(prefers-reduced-motion: reduce)').matches;
let lenis = null;
if (!reduced && window.Lenis) {
  lenis = new Lenis({
    duration: 1.2,                    // inertia time: sweet spot 1.0–1.2
    easing: t => Math.min(1, 1.001 - Math.pow(2, -10 * t)),
    smoothWheel: true,
    syncTouch: false,                 // keep touch native — smoothing it feels floaty
  });

  // the three-line GSAP ScrollTrigger sync (plain rAF loop if no GSAP)
  lenis.on('scroll', ScrollTrigger.update);
  gsap.ticker.add((time) => lenis.raf(time * 1000));
  gsap.ticker.lagSmoothing(0);

  // route anchors through Lenis
  document.querySelectorAll('a[href^="#"]').forEach(a =>
    a.addEventListener('click', e => {
      const el = document.querySelector(a.getAttribute('href'));
      if (el) { e.preventDefault(); lenis.scrollTo(el, { offset: -80 }); }
    }));
}
</script>
✏️ Exercise — try it on your site. Open your portfolio draft portfolio-site-draft/index.html: (1) add the one-line Lenis CDN to <head>; (2) paste the init above and scroll for 10 seconds; (3) route your nav anchors through lenis.scrollTo (offset for the nav height); (4) turn on "reduce motion" in your OS settings and refresh — confirm the page falls back to native scrolling with everything working.
⚠️ Gotcha (the #1 beginner crash): delete scroll-behavior: smooth. CSS smooth scrolling fights Lenis — anchor jumps stutter mid-flight and the wheel feels sticky. Rule: on a Lenis page, html must be scroll-behavior: auto; smoothing is Lenis' job alone.
💡 Portfolio cheat sheet: Lenis on site-wide; duration 1.0–1.2s is the butter zone; every anchor nav goes through scrollTo; sync Day 4's GSAP work with the three lines; under prefers-reduced-motion don't initialize at all — respect starts here (Day 8 covers this systematically).
