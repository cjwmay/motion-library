Day 2 · Refined hover micro-interactions

Refinement = easing with personality + restraint in timing + a complete return trip. Each effect below comes in 2–3 variants, side by side — hover them yourself and pick the one that feels right. That pick becomes your site's personality.

01Easing is personality

Same 4px lift — the easing decides whether it feels mechanical or refined. Ease-out curves (e.g. cubic-bezier(.22,1,.36,1)) start fast and settle slow, closest to how things move in the physical world. Overshoot is for playful contexts, not serious buttons.

02Magnetic button: restraint is a virtue

The button gets pulled toward the cursor. Refinement is about strength — around 0.25 feels just right; above 0.45 it gets greasy. Note the return trip: the transition lives on the element itself, so it glides back when the cursor leaves.

033D tilt: convince the brain it's solid

Bare tilt looks like a wobbling sheet of paper. Add a cursor-following highlight and a deepening shadow, and the brain reads it as an object with thickness — the side dishes create the refinement.

05Image zoom: slow reads premium

Slow + subtle (1.06 over 1.4s) reads premium; fast + large (1.15 over 0.5s) reads cheap. Use the slow one for every case-study cover.

Exercise

Open this file's source, change the second magnetic button's data-strength="0.28" to 0.5, then to 0.15 — walk the full spectrum from "greasy" to "restrained" to "numb" by hand. Then write down your number — it becomes your site's standard button strength.

Pitfall

Put transition on the element itself, never inside :hover. In :hover, the moment the cursor leaves the transition is gone and the element snaps back instantly — all that refinement wasted. The most common hover-motion fail.

Where to use it in your portfolio

  • Nav links → 04's scaleX growing underline
  • CTA buttons → 02's magnetic (0.28) + 01's ease-out
  • Case cards → 03's refined tilt
  • Case cover images → 05's slow zoom
