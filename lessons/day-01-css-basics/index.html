Day 1 · The CSS motion trio

The foundation of all web motion — transition controls how it changes, transform controls what changes (move / scale / rotate), and easing controls the rhythm of the change. Hero title entrances, button hovers, card lifts — it's all combinations of these three.

Designing for AI

Code

.btn {
  padding: 12px 28px; border-radius: 999px;
  background: #6c4dff; color: #fff; border: none;
  /* Only transition transform and opacity (GPU-accelerated, no jank) */
  transition: transform .35s cubic-bezier(.2,.7,.2,1.2),
              box-shadow .35s ease;
}
.btn:hover {
  transform: translateY(-4px) scale(1.04); /* lift + subtle scale */
  box-shadow: 0 12px 24px rgba(108,77,255,.35);
}
.hero-title span {
  display: inline-block; opacity: 0;
  transform: translateY(30px);
  animation: rise .8s cubic-bezier(.2,.7,.2,1) forwards;
}
.hero-title span:nth-child(2) { animation-delay: .12s; }
.hero-title span:nth-child(3) { animation-delay: .24s; }
@keyframes rise { to { opacity: 1; transform: none; } }

Exercise

Change translateY(-4px) to -10px, and .35s to .15s and .8s — feel the difference between "too snappy" and "too sluggish". Find the timing that feels right to you and keep it as your site's standard duration.

Pitfall

Animate only transform and opacity. Animating top / left / width / margin triggers layout reflow and drops frames on mobile — the most common source of jank for beginners.

Where to use it in your portfolio

  • Hover feedback on every button
